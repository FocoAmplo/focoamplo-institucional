# Foco Amplo Imóveis

Este diretório reúne os materiais digitais do escopo imobiliário da Foco Amplo: site, posicionamento e conteúdo para redes sociais.

## Estrutura

- `site/index.html`: página institucional de Foco Amplo Imóveis.
- `redes-sociais/perfis.md`: textos-base para WhatsApp, Instagram, Facebook e LinkedIn.
- `redes-sociais/publicacoes.md`: modelos de publicações para revisão e adaptação.

## Posicionamento

Conexão de proprietários, compradores, investidores, construtoras e empresas com oportunidades em imóveis, terrenos, áreas para desenvolvimento e pontos estratégicos para eletropostos e mídia publicitária.

## Limite do repositório

Este projeto está organizado em uma pasta própria dentro do repositório institucional já existente. O arquivo `index.html` na raiz e a publicação atual foram preservados. A criação de um repositório GitHub separado não está disponível nesta conexão; esta estrutura permite manter o trabalho no mesmo lugar enquanto isso.

A página deste diretório é uma versão de trabalho. Antes de substituir o site publicado ou alterar DNS/domínio, revisar e publicar a versão aprovada pela equipe.

## Atualização

Registre cada alteração em um commit com mensagem objetiva. Revise links, telefone, dados dos imóveis, autorizações e informações comerciais antes de publicar conteúdo.
