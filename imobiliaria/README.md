# Foco Amplo Conexões

Este diretório reúne os materiais digitais da marca **Foco Amplo Conexões**: site, posicionamento e conteúdo para redes sociais.

## Estrutura

- `site/index.html`: página institucional.
- `redes-sociais/perfis.md`: textos padronizados para Instagram, Facebook, LinkedIn e WhatsApp.
- `redes-sociais/publicacoes.md`: modelos de publicações.
- `redes-sociais/integracao-canais.md`: roteiro para integrar e revisar os canais.

## Posicionamento

Conectamos pessoas e empresas a oportunidades em imóveis, terrenos, áreas para desenvolvimento e pontos estratégicos para eletropostos e mídia publicitária.

O projeto está em uma pasta própria dentro do repositório institucional existente. A página principal na raiz do repositório e sua publicação atual foram preservadas. A página desta pasta é uma versão de trabalho; revisar e aprovar antes de publicar ou alterar domínio.

Registre cada alteração em commit com mensagem objetiva. Confira links, telefone, dados e autorizações antes de publicar.
